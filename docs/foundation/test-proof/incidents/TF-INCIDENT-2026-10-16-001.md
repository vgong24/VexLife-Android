## Why this incident matters

The dangerous pattern was:

~~~text
red
-> retry
-> green
-> normalize first red as noise
-> lose recurrence history
-> later failure looks newly introduced
~~~

That would let a flaky proof substrate become habitual before enough downstream features made the
problem expensive.

The integrity issue is therefore broader than one flaky test:

> the proof system exhibited an intermittent failure while also losing the evidence needed to
> recognize recurrence.
